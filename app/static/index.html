Speaker-labelling study

Fix the computer's mistakes about who is speaking, and when.

Before you start

You will do a short series of trials. In each trial you see a sound clip with coloured blocks — one colour per speaker. The computer has already guessed the labels, but some are wrong. Your job is to correct them.

  • Some trials are done with the mouse, others with the physical tokens on the printed sheet. The screen tells you which, every time.
  • The first trial of each kind is a practice run — it does not count, so take your time to get used to it.
  • There is no right pace. When a trial looks fixed, press Done to move on.
